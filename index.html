Setting up Home Device

A step-by-step guide to turning off the Google Play Store on a phone — and keeping it off. No experience needed.

No more new apps. The Play Store is removed, so nothing new can be installed.
It stays that way. The settings are locked so they can’t be switched back on from the phone.
Apps still get updates. The apps already on the phone can be kept up to date without the store.

This is meant to be permanent

Once it’s set up, the app store cannot be switched back on from the phone itself. Only a person who knows the operator passphrase can undo it (see the last section). Make sure that’s what you want before you start.

Before you start
  • The phone, charged, with Wi-Fi turned on and connected.
  • About 20 quiet minutes.
  • The Google account email and password used on the phone (you’ll sign out and back in).
  • The app file and the operator passphrase from whoever gave you this guide. (Getting the file onto the phone is Step 1 — no browser needed.)

Part-way through you’ll sign out of your accounts for a few minutes. Nothing is deleted — you add them back at the end.

A few new words
App file
Also called an APK. It’s just an Android app saved as a file, so you can install it without the store.
Settings
The phone’s own options screen — the gear icon.
Developer options
An extra menu that’s hidden until you unlock it. Step 3 shows how.
Manager mode
What Home Device switches into so it’s allowed to control the phone. Its proper name is “Device Owner.”
Two ways to set up
Easiest

Brand-new or reset phone

On the very first welcome screen, tap the screen 6 times and scan the QR code your setup person gives you. The phone does the rest. Then skip to Step 7.

Most phones

A phone already in use

Follow Steps 1–8 below. It takes a little longer but doesn’t erase anything on the phone.

Step by step · phone already in use

Get the app file onto the phone

No web browser is needed on the phone. You get the app file (its name ends in .apk), copy it onto the phone, and install it.

On a computer, download the app file from this link, then move it to the phone with one of the ways below:

https://github.com/chayasiem-bit/home-device/releases/latest/download/home-device.apk

Ways to get the file onto the phone:

  • Bluetooth — pair the phone with a computer or another phone and send the file.
  • Nearby Share / Quick Share — send it from another Android phone.
  • microSD card — put the file on a card using a computer, then slot the card into the phone.
  • USB cable — plug the phone into a computer, pick File transfer on the phone, and copy the file over.

Then install it:

  • Open the Files app, go to where the file landed (often Downloads, Bluetooth, or the SD card), and tap the file.
  • If it says installing is blocked, tap Settings on the pop-up, turn on Allow from this source, go back, and tap Install.
  • If it warns “this file can harm your device,” that’s normal for any app from outside the store. Tap Install anyway / OK.
Don’t have the file yet? Ask your setup person to send it by Bluetooth, Nearby Share, or on an SD card — it’s one file ending in .apk.

Sign out of your accounts

The phone only hands control to the Blocker when no accounts are signed in. This is temporary.

  • Go to Settings › Accounts (sometimes “Passwords & accounts”).
  • Tap each account and choose Remove — Google and any apps listed (WhatsApp and the like).
Nothing is deleted. You sign back in at Step 7.

Unlock the hidden menu

Reveal “Developer options.”

  • Go to Settings › About phone.
  • Find Build number and tap it 7 times quickly. A message says “You are now a developer.”

Turn on Wireless debugging

This lets the Blocker talk to the phone to set itself up.

  • Go to Settings › System › Developer options (it’s there now).
  • Turn on Wireless debugging. If it asks “Allow on this network?”, tap Allow.

Open the Blocker and start setup

Begin the guided connection.

  • Open the Home Device app.
  • Tap Set up (pair device).

Connect it

Link the app to the phone with a one-time code.

  • In the app, tap Discover ports automatically. The two number boxes should fill in by themselves.
  • On the phone, in Wireless debugging, tap Pair device with pairing code. It shows a 6-digit code.
  • Type that code into the app and tap Pair, then tap Activate device owner.

When it says “Device Owner: active — Play Store blocked,” it’s done and in charge.

If the boxes didn’t fill in: the pairing pop-up shows a number after a colon (like :37881) — type it in the Pairing port box. After you pair, the main Wireless debugging screen shows another number after a colon — type it in the Connect port box.

Add your accounts back

Put things back the way they were.

  • Go to Settings › Accounts › Add account.
  • Sign back into Google and any apps you removed.

Check it worked

Confirm the store is gone.

  • Open the phone’s list of apps.
  • The Play Store is gone, and it can’t be reinstalled from the phone.

That’s it — the phone is set up.

If you ever need to undo it

Open Home Device, tap Release device (operator), type the operator passphrase, and tap Release. The lock lifts and the phone goes back to normal.

Without that passphrase it can’t be undone from the phone — that’s the point of it.

If something goes wrong
It won’t let me install the app file
When you open the file, tap Settings on the pop-up, turn on Allow from this source (or “Install unknown apps”), go back, and tap Install.
I can’t find “Developer options”
It’s hidden until you unlock it. Go to Settings › About phone and tap Build number 7 times (Step 3). Then it appears under Settings › System.
“Discover ports” didn’t fill in the boxes
Type the numbers by hand. The pairing pop-up and the main Wireless debugging screen each show a number after a colon (like 192.168.0.5:37881) — use the part after the colon. See the note under Step 6.
Will removing my accounts delete my photos or chats?
No. Removing an account just signs you out. Your photos and files stay, and you sign back in at Step 7.
How do I get the app file without a browser?
You don’t download it on the phone. Your setup person sends you the file (it ends in .apk) — by Bluetooth, Nearby Share, on a microSD card, or over a USB cable from a computer. Then open the Files app and tap it (Step 1).
Can apps still be removed after setup?
Yes. Removing apps is left switched on, so you can uninstall apps as normal. Only Home Device itself can’t be removed — and no new apps can be added, because the store is gone and installing from files is blocked.
The pairing or activation step shows an error
Check that you removed all accounts (Step 2) and that Wi-Fi and Wireless debugging are both on. Then close the app, open it again, and retry Step 6.

Keep this guide handy in case you set up another phone. If you get stuck on any step, send your setup person a photo of what’s on the screen.
